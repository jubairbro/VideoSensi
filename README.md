
# videosensi

**videosensi** হলো একটি প্রো লেভেল ভিডিও কম্প্রেসর টুল Termux এর জন্য। এটি ব্যবহার করে সহজেই ভিডিওর সাইজ কমিয়ে নেওয়া যায়, কোয়ালিটি ঠিক রেখে। একাধিক কম্প্রেশন অপশন, ব্র্যান্ডেড ইন্টারফেস, টেলিগ্রাম ইনভাইট, আপডেট সিস্টেম সবই রয়েছে।

## Features

- Multiple Compression Levels (10%–50%)
- Quality maintained using CRF (libx264)
- Branded output filename (_JUBAIR.mp4)
- Automatic storage setup and output folder creation
- Shows original and compressed size
- GitHub-based update checker (`videosensi-update`)
- Friendly UI with progress messages
- Telegram join prompt after processing

## Installation

```
pkg install git -y
git clone https://github.com/jubairbro/videosensi
cd videosensi
bash setup.sh
```

##Usage

```videosensi```

##Update

```videosensi-update```
