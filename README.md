# videosensi

A blazing fast video compressor tool for Termux using FFmpeg.

---

## Installation

```bash
pkg install git -y
git clone https://github.com/jubairbro/videosensi
cd videosensi
bash setup.sh
```

---

## Usage

```bash
videosensi
```

---

## Update

```bash
videosensi-update
```
